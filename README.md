# Yara AI v13.0 - Ultimate Master Release

Dedicated Autonomous AI Assistant, Data Analyst Companion & Girlfriend Companion built for **HASHIM** (`@hashim_m4x`).

## 🛠 Complete Error-Free Architecture:
- Fully integrated Gradle Version Catalog (`libs.versions.toml`).
- Pre-configured GitHub Actions workflow (`.github/workflows/build.yml`) with automated `chmod +x gradlew`.
- Jetpack Compose dark-theme UI with bottom navigation, responsive chat bubbles, and emotion status engine.
- Complete Android permissions added to `AndroidManifest.xml` (Storage, Camera, Audio, Notifications, Internet).

## 🚀 How to Build APK via GitHub Actions:
1. Extract `YaraAI-v13.zip` on your computer or phone.
2. Push all extracted files directly to the root of your GitHub repository.
3. Open the **Actions** tab on GitHub -> **Build Yara APK v13**.
4. Download `YaraAI-v13-Debug-APK` artifact and install `app-debug.apk` on your Android device!
